# Contributing

This repository is a mirror. The plugin is developed in
[krelltunez/dayGLANCE](https://github.com/krelltunez/dayGLANCE), under
`dayglance-obsidian-plugin/`, next to the dayGLANCE app and the shared packages
it is tested against, and copied here automatically. Changes made directly in
this repository are overwritten by the next copy.

Please open issues and pull requests in
[krelltunez/dayGLANCE](https://github.com/krelltunez/dayGLANCE).
